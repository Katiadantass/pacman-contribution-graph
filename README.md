# 👾 Pac-Man Contribution Graph

Animação em estilo Pac-Man que transforma o gráfico de contribuições do GitHub em uma representação divertida e interativa.

Este projeto utiliza GitHub Actions para gerar automaticamente imagens SVG com a animação do Pac-Man, permitindo personalizar o README de um perfil GitHub.

## 🎮 Demonstração

### Tema claro

![Pac-Man Contribution Graph](https://raw.githubusercontent.com/Katiadantass/pacman-contribution-graph/output/pacman-contribution-graph.svg)

### Tema escuro

![Pac-Man Contribution Graph Dark](https://raw.githubusercontent.com/Katiadantass/pacman-contribution-graph/output/pacman-contribution-graph-dark.svg)

## ⚙️ Como funciona

A geração das animações é realizada por meio do GitHub Actions.

* Atualização automática programada.
* Execução quando há alterações na branch `main`.
* Possibilidade de execução manual pelo GitHub Actions.
* Arquivos SVG publicados na branch `output`.

## 💻 Utilização no perfil GitHub

Para exibir a animação em um README, utilize:

```html
<img src="https://raw.githubusercontent.com/Katiadantass/pacman-contribution-graph/output/pacman-contribution-graph.svg" alt="Pac-Man Contribution Graph" width="100%"/>
```
